termesh playground

A 3D renderer written from scratch, drawing with text. This is the real program, compiled to WebAssembly and running in a terminal emulator in your browser. No GPU is involved.

Your own model

Drop a file anywhere on the page: .glb, .gltf, .obj, .stl or .ply. For a model in several files (a .gltf with its .bin and textures, an .obj with its .mtl) drop them all together. Nothing is uploaded: the file is read by this page and goes no further.
